Para verlo en tu Mac

Abrí Ver_Pulp.command desde la carpeta descomprimida. Necesitás Node.js 20.11 o superior; no se instalan paquetes. El servidor abre automáticamente un puerto disponible.

La vista es navegable, con datos de muestra y acciones financieras deshabilitadas.

Para actualizar GitHub

El código todavía no fue subido por el asistente. Publicar_en_GitHub.command usa la autenticación Git de tu Mac, revisa la versión de origen y ejecuta pruebas. Te pide escribir PUBLICAR antes de enviar un commit al mismo repositorio.

No hace force push. Si la rama cambió, se detiene. La URL actual no cambia hasta que se publique la actualización.
