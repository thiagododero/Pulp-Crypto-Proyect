# Fuentes primarias consultadas para la implementación

Consulta: 9 de noviembre de 2026. Estas referencias documentan interfaces y formatos, no certifican nuestro código. Revisar versiones y programas antes de habilitar fondos reales.

- Jupiter Swap v2: https://developers.jup.ag/docs/swap/order-and-execute
- Jupiter Earn: https://developers.jup.ag/docs/lend/earn/api
- Jupiter Trigger auth: https://developers.jup.ag/docs/trigger/authentication
- Helius, historial paginado/ATA: https://www.helius.dev/docs/rpc/gettransactionsforaddress
- Raydium SDK oficial (CPMM): https://github.com/raydium-io/raydium-sdk-V2/tree/master/src/raydium/cpmm
- Raydium SDK oficial (LaunchLab instrucciones/layout/curvas): https://github.com/raydium-io/raydium-sdk-V2/tree/master/src/raydium/launchpad
- Squads v4 SDK/IDL oficial: https://github.com/Squads-Protocol/v4/tree/main/sdk/multisig
- Pinata JSON: https://docs.pinata.cloud/api-reference/endpoint/ipfs/pin-json-to-ipfs
- Supabase RLS: https://supabase.com/docs/guides/database/postgres/row-level-security
- Caddy reverse proxy: https://caddyserver.com/docs/caddyfile/directives/reverse_proxy
- Solana RPC: https://solana.com/docs/rpc

Los constructores binarios nativos incluidos no importan automáticamente el SDK remoto: deben compararse con las versiones desplegadas. No hay dependencias descargadas por el lanzador. No se confunde consultar documentación con probar una transacción contra un protocolo real.
