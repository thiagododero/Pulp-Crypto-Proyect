# Documentación primaria consultada

Consulta: 9 de noviembre de 2026. Las APIs pueden cambiar; reconfirmar en la validación con credenciales del operador.

- Jupiter Order & Execute: https://developers.jup.ag/docs/swap/order-and-execute
- Jupiter Get Order: https://developers.jup.ag/docs/api-reference/swap/order
- Jupiter Earn API (Beta): https://developers.jup.ag/docs/lend/earn/api
- Wallet Standard: https://wallet-standard.github.io/wallet-standard/
- W3C contraste mínimo: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum

La integración usa `maxSupportedTransactionVersion=0`; no afirma soporte de mensajes v1. La API key se guarda en el servidor local. Las ilustraciones nuevas fueron generadas para el proyecto y se incluyen como recursos rasterizados con transparencia; el logo y los iconos se reutilizan de la beta de Pulp aportada en la conversación.

No hay estadísticas de mercado, rendimientos ni métricas comerciales inventadas en las pantallas de producción. Los fixtures de prueba están aislados bajo `tests/` y no los importa el servidor normal.
